# Bileklik

JCV8 bileklik için iOS ve Android sağlık uygulaması.

## Ortak geliştirici için başlangıç notu

Claude Code'u bu repoda iki yoldan kullanabilirsiniz:

1. **Web'de:** [claude.ai/code](https://claude.ai/code) adresine girin, GitHub'ı bağlayın, Bileklik reposunu seçip
   görevi yazın. Claude bulutta çalışır, değişiklikleri bir dala gönderip PR açar.
2. **Bilgisayarda:** Claude Code'u kurun, repoyu klonlayın, klasörde `claude` yazıp görevi anlatın:
   ```
   npm install -g @anthropic-ai/claude-code
   git clone https://github.com/gungoryener-source/bileklik
   cd bileklik
   claude
   ```

Her iki yolda da repodaki `CLAUDE.md` dosyası Claude'a projenin kurallarını otomatik öğretir.
